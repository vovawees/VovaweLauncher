VOVAWELAUNCHER / DEAD MILE '96 API REFERENCE

BASE URL:
http://130.61.29.17:8000

AUTHENTICATION HEADERS:
Client endpoints require:
Authorization: Bearer <session_token>

Internal endpoints require:
X-Internal-Key: <INTERNAL_API_KEY>

RESPONSE FORMAT:
Success:
{
  "ok": true,
  "data": { ... },
  "message": "...",
  "status_code": 200
}

Error:
{
  "ok": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "Human readable error message",
    "details": { ... }
  },
  "status_code": 400
}

ENDPOINTS LIST:

1. Health & Docs
GET /health -> {"ok": true, "data": {"status": "alive"}}
GET /docs -> Swagger UI documentation
GET /openapi.json -> OpenAPI 3.1 specification

2. Static Client Downloads
GET /files/<path> -> Direct download of client file (e.g. /files/mods/jei.jar)

3. Auth (/api/v1/auth)
POST /api/v1/auth/tg/init
  Request: {"purpose": "register"} or {"purpose": "reset_pw"}
  Response: {"token": "reg_...", "bot_url": "https://t.me/BotName?start=reg_...", "expires_in": 600}

GET /api/v1/auth/tg/poll?token=reg_...
  Response: {"status": "verified" | "pending" | "expired", "verified": true/false, "tg_username": "..."}

POST /api/v1/auth/register
  Request: {
    "reg_token": "reg_...",
    "username": "SurvivorName",
    "password": "Password123",
    "device": {
      "hwid_hash": "...",
      "os_name": "linux",
      "os_version": "...",
      "arch": "x86_64",
      "cpu_info": "...",
      "gpu_name": "...",
      "gfx_backend": "vulkan",
      "ram_total_mb": 16384,
      "launcher_version": "0.1.0",
      "launcher_hash": "..."
    }
  }
  Response: {
    "session_token": "dm_...",
    "expires_at": 1731999999,
    "user": {"id": 1, "account_uuid": "...", "username": "SurvivorName", "role": "player"}
  }

POST /api/v1/auth/login
  Request: {"username": "SurvivorName", "password": "...", "device": {...}}
  Response: {"session_token": "dm_...", "expires_at": ..., "user": {...}}

POST /api/v1/auth/reset-password
  Request: {"reset_token": "rst_...", "new_password": "..."}

POST /api/v1/auth/logout [Auth Required]
